title: "Drag-to-reassign notes between stems"
status: pending
crate: "rifflab-ui"
requirement: "FR-M7 (Phase 3)"
---

Enable dragging notes from one stem's lane to another in the piano roll view. This allows the user to correct stem assignment errors where a note was detected in the wrong stem. The reassignment updates the underlying NoteEvent data and the visual display. Provide visual feedback during the drag showing the target stem.
