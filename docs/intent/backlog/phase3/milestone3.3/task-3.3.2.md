title: "Adaptive tempo"
status: pending
crate: "rifflab-practice"
requirement: "FR-M5 (Phase 3)"
---

Automatically slow down difficult passages based on real-time accuracy measurement. When the player's accuracy drops below a threshold in a section, reduce the playback tempo for that section. Gradually increase the tempo as the player improves across sessions. Integrate with the time-stretching system for seamless tempo changes.
