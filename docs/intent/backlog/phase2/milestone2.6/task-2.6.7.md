Implement reusable rotary knob and linear fader widgets for the UI toolkit. The knob widget supports drag-to-adjust (vertical drag for value change), displays the current value, and supports configurable range and default. The linear fader widget provides a vertical or horizontal slider. Both widgets are used in the effects editor and sidebar panels.
